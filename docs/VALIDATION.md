# 版本验证范围

本项目提供可自行复测的源码测试与实际包验收工具。测试网页及截图中的数据均为虚构，不属于真实品牌样本。

| 项目 | 验证内容 |
| --- | --- |
| Windows 程序包 | 原生 exe、无外部 Python/AI 命令、只填品牌创建项目、中文输入、端口冲突、重复启动、PDF、证据导出、退出重开与资料保留 |
| Linux 程序包 | Debian 12 / x86_64 原生 ELF、同一组实际包验收条件 |
| Linux 图形显示 | 在 Xvfb 中运行生产 Workspace 源码，验证真实浏览器窗口输入和测试 Cookie 保存重开；不是实体桌面或真实账号验证 |
| 平台采集行为 | 三平台本地页面测试覆盖新回答、发送确认、登录中断、繁忙、页面过渡和完成判定 |
| 真实官网 | Windows 先前版本已取得三平台官网完整回答；发布版自动化检查不代表每台收件人电脑或其账号均已通过 |
| 未验证 | 收件人的真实 Linux 桌面及其账号、Mac 原生包、Linux ARM、长期无人值守 |

本版新增了「只输入品牌名」的产品接口和实际包界面检查。完整发布检查结果及安装包 SHA256 随 Release 提供，测试日志不包含开发者数据库或登录资料。

首次使用时请在 DeepSeek、豆包、Kimi 各采集一题，核对完整原文、日期、地址和截图，再扩大批次。排名、评价和引用需人工复核，失败记录不计入有效样本。
