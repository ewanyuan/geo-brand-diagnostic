GEO 诊断台 Linux 本机试用版 0.3.1

本包用于 x86_64（常见 Intel/AMD 64 位）Linux 桌面。
构建基线为 Debian 12、glibc 2.36；可在相同或更新基线的发行版上试用。
ARM 电脑、较旧发行版和没有桌面的服务器请勿使用此包。

开始使用
1. 完整解压 tar.gz，不要只取出其中一个文件；保留 _internal 文件夹。
2. 在桌面中运行 geo-diagnostic，或在解压目录的终端运行 ./启动GEO.sh。
3. 程序会打开本机浏览器界面。输入品牌名创建项目；品类、地区和竞品可选填。
4. 到「录入监测」打开平台，在 GEO 启动的独立浏览器中自行登录 DeepSeek、豆包和 Kimi。
5. 回到 GEO，选择平台和问题，点「开始提问并保存回答」，逐个平台重复。
6. 查看原文和截图，核对并填写排名、评价和引用，再查看统计、打印或保存 PDF。
7. 「导出证据包」可带走 CSV、原回答和截图；「退出 GEO」会保存资料并关闭本机服务。

收件人需要 Chrome、Edge 或系统 Chromium、可访问平台官网的网络及自己的账号。
无需安装 Python、Node 或任何 AI 工具。提问过程中请不要手动操作正在采集的聊天页。
程序只监听本机，不把项目或登录资料交给 248 服务器。

Linux 原生程序已在隔离环境验证启动、浏览器中文输入、复核界面、PDF、证据导出、退出重开和数据保留。
这些测试不代表已在所有 Linux 桌面或收件人的真实账号上验收。
首次使用请先在每个平台各采集一题，确认得到完整回答与截图后再扩大批次。
名次、评价和引用需要人工核对；账号失效、限流或人机验证需要本人处理。

资料默认保存在 ~/.local/share/GeoBrandDiagnostic；设置了绝对路径 XDG_DATA_HOME 时使用 $XDG_DATA_HOME/GeoBrandDiagnostic。
如果旧版已有 ~/GeoBrandDiagnostic，则沿用旧位置。
data 是项目与证据，browser-profile 是专用登录资料。更新前先点「退出 GEO」，再替换程序目录。
请勿将自己的整个资料目录发给别人；证据导出包不含浏览器登录资料，分享截图前仍请核对账号信息。
